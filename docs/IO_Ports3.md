Отлично! Добавляю колонку с конкретными адресами внутри MMIO-пространства, начинающегося с `0xC000`.

Идея с выравниванием устройств на 256 байт (с шагом `+0x100`) — **идеальна**. Это делает адреса запоминающимися (`C000`, `C100`, `C200`...) и оставляет каждому устройству огромное пространство для регистров.

### Как этим пользоваться программисту в LX-режиме:

1.  **Прямой доступ (самый быстрый):**
    ```asm
    ; Заранее известно, что регистр палитры видеочипа находится по MMIO-адресу 0xC322
    LD A, %00001111       ; Цвет
    LD (0xC322), A        ; Прямая запись по адресу в памяти
    ```

2.  **Доступ через 8-битный порт (для совместимости с кодом, который работает и в Legacy):**
    ```asm
    ; Установить страницу, где находится видеочип (его MMIO-адреса начинаются с 0xC300)
    LD A, 0xC3            ; Старший байт адреса видеочипа -> в регистр PAGE
    OUT (0xD3), A         ; Записали его через порт MMIO_PAGE

    ; Теперь обращение к порту 0x22 попадет в MMIO-адрес 0xC322
    LD A, %00001111       ; Цвет
    OUT (0x22), A         ; Записали цвет в регистр палитры через 8-битное окно
    ```

Это архитектурно чисто, мощно и предоставляет программисту выбор между максимальной производительностью и универсальностью.
