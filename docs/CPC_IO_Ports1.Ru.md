# Спецификация памяти и ввода-вывода: Aleste LX

## 1. Философия и Основные Принципы

1.  **Двойная Реальность (Dual Reality):** Система функционирует в двух фундаментально разных режимах, переключаемых глобально.
    *   **Режим Совместимости (Legacy Mode):** Полная эмуляция Amstrad CPC 6128 и Aleste 520EX. Все порты CPC и неконфликтующие порты Aleste (например, маппер `7C-7Fxx`) работают нативно. Конфликтующие порты Aleste (например, USART на `EFxx`) отключены.
    *   **Расширенный Режим (Native Mode):** Включает всю современную периферию Aleste LX (MMU, новый звук, сеть). Обращения к конфликтующим портам CPC (например, `FADC`, `FBDC`) перехватываются и эмулируются гипервизором.

2.  **Единая Точка Управления:** Все регистры управления системой (MMU, PIC, режимы) доступны через единое MMIO-пространство, чтобы избежать путаницы.

3.  **Трехуровневая Адресация:**
    *   **Z80 View:** 64KB адресного пространства + 64KB портов ввода-вывода.
    *   **MMU View:** 22-битное физическое адресное пространство (4 МБ), организованное в 4 слота.
    *   **Wishbone View:** 24-битное физическое адресное пространство (16 МБ) с зеркалированием устройств для изоляции.

## 2. Управление памятью (MMU) и Слотинг

Управление осуществляется через порты в пространстве ввода-вывода Z80. Эти порты доступны в любом режиме.

| Порт Z80 | Режим | Назначение                                                                                               |
| :------- | :---- | :------------------------------------------------------------------------------------------------------- |
| `0xDBXX` | Оба   | **Выбор активного слота (Slot Select).** Записываемое значение (0-3) выбирает слот, чьи банки видны ниже. |
| `0xDCXX` | Оба   | **Банк для страницы 0 (0000-3FFF) активного слота.**                                                     |
| `0xDDXX` | Оба   | **Банк для страницы 1 (4000-7FFF) активного слота.**                                                     |
| `0xDEXХ` | Оба   | **Банк для страницы 2 (8000-BFFF) активного слота.**                                                     |
| `0xDFXX` | Оба   | **Банк для страницы 3 (C000-FFFF) активного слота.** *В Режиме Совместимости* также управляет верхним ROM. |

**Важно:** Запись в `0xDFXX` в **Режиме Совместимости** имеет двойную природу: она изменяет и банк RAM в слоте, и регистр верхнего ROM CPC. В **Расширенном Режиме** это просто банк RAM.

## 3. Memory-Mapped I/O (MMIO)

16KB область в конце адресного пространства Z80 (`0xC000-0xFFFF`) отводится под MMIO. Чтобы избежать коллизий с RAM/ROM, доступ к этой области всегда перенаправляется на системную шину, независимо от настроек маппера.

Содержимое MMIO-окна управляется **регистром страницы MMIO (MMIO Page Register)**, расположенным по адресу `0xC00F` в самом MMIO.

| Адрес в MMIO | Режим       | Назначение                                                                |
| :----------- | :---------- | :------------------------------------------------------------------------ |
| `0xC00F`     | Только запись | **Регистр страницы MMIO.** Выбирает, какой банк устройств отображается в окне `0xC000-0xC0FF`. |

**Страницы MMIO (Пример):**
*   `0x00`: Системные регистры (MMU, управление режимами)
*   `0x01`: Контроллер прерываний (PIC)
*   `0x02`: Звуковой контроллер (SoundMagic 2)
*   `0x03`: Графический ускоритель
*   `0x04`: DMA-контроллер
*   `0xFE`: Зеркало портов Aleste 520EX (USART, EXTPORT)
*   `0xFF`: Зеркало портов Amstrad CPC (CRTC, PPI, FDC)

Это решает проблему коллизий: в любой момент времени в первых 256 байтах MMIO-окна (`0xC000-0xC0FF`) видна только одна страница устройств.

## 4. Контроллер Прерываний (Master PIC)

Контроллер использует иерархическую модель. Центральный PIC фиксирует запросы от групп устройств.

| Адрес доступа           | Режим | Назначение                                                                                               |
| :---------------------- | :---- | :------------------------------------------------------------------------------------------------------- |
| **CPC:** `0xF8XX`       | Legacy | Резерввировано для будущего контроллера прерываний.                                                        |
| **8-Bit Classic:** `0x10` | Native | Страница MMIO `0x01`, смещение `0x10`.                                                                     |
| **MMIO:** `0xC010`      | Native | Прямой доступ (при активированной странице `0x01`).                                                        |

**Регистры Central PIC (доступны по базовому адресу, e.g., `0xC010`):**

| Смещение | R/W | Назначение           | Описание                                                                                              |
| :------- | :-- | :------------------- | :---------------------------------------------------------------------------------------------------- |
| `+0x00`  | R   | **IRQ Status**       | Флаги запросов на прерывание. Бит установлен == запрос активен.                                         |
| `+0x01`  | R/W | **IRQ Mask**         | Маска прерываний. Бит установлен == прерывание *разрешено*.                                          |
| `+0x02`  | W   | **IRQ Acknowledge**  | Сброс флага. Запись `1` в бит сбрасывает соответствующий флаг в регистре статуса.                      |

**Формат регистра статуса (IRQ Status):**

| Бит | Группа         | Источник прерывания                                                                                    |
| :-- | :------------- | :----------------------------------------------------------------------------------------------------- |
| 7   | **EXT_SLOT**   | Ошибка доступа к внешнему слоту (таймаут).                                                               |
| 6   | **BUS_CRASH**  | Нарушение защиты памяти (запись в ROM, чтение из "дыр").                                                 |
| 5   | **SUPER_BTN**  | Аппаратная кнопка вызова супервизора.                                                                   |
| 4   | **LEGACY**     | Группа legacy-устройств (объединенный сигнал от CTC, VDP, старого UART).                               |
| 3   | **AUDIO**      | Звуковой контроллер (SoundMagic 2).                                                                    |
| 2   | **GPU**        | Графический контроллер (VBlank, HBlank).                                                               |
| 1   | **DMA_COM**    | DMA-контроллер или высокоуровневый коммуникационный контроллер (Ethernet).                             |
| 0   | **STORAGE**    | Контроллеры хранения (FDC, SD-карта).                                                                  |

Обработчик в ПЗУ, получив сигнал от центрального PIC, опрашивает регистры статуса конкретных устройств для детализации причины прерывания.

## 5. Регистры Супервизора и Управления Системой

Эти регистры доступны **только в Расширенном Режиме** и mapped на несколько страниц MMIO для удобства.

| Адрес доступа           | Режим | Назначение                                                                             | Описание                                                                                              |
| :---------------------- | :---- | :------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------- |
| **MMIO Page 0x00:**     |       |                                                                                        |                                                                                                       |
| `0xC000`                | Native| **BANK_0**                                                                             | Банк для страницы 0 текущего слота (зеркало порта `0xDCXX`).                                            |
| `0xC001`                | Native| **BANK_1**                                                                             | Банк для страницы 1 текущего слота (зеркало порта `0xDDXX`).                                            |
| `0xC002`                | Native| **BANK_2**                                                                             | Банк для страницы 2 текущего слота (зеркало порта `0xDЕXX`).                                            |
| `0xC003`                | Native| **BANK_3**                                                                             | Банк для страницы 3 текущего слота (зеркало порта `0xDFXX`).                                            |
| `0xC004`                | Native| **CURRENT_SLOT**                                                                       | **Только для записи из кода супервизора.** Устанавливает активный слот.                               |
| `0xC005`                | Native| **GLOBAL_CTRL**                                                                        | Бит 0: Режим (0=Legacy, 1=Native). Бит 1: Защита от записи для пользовательских слотов.                 |
| `...`                   |       |                                                                                        |                                                                                                       |
| `0xC00F`                | Native| **MMIO_PAGE_SEL**                                                                      | Выбор страницы MMIO для окна `0xC000-0xC0FF`.                                                         |
| **MMIO Page 0x01:**     |       |                                                                                        |                                                                                                       |
| `0xC010`                | Native| **IRQ_STATUS**                                                                         | Состояние прерываний (Master PIC).                                                                    |
| `0xC011`                | Native| **IRQ_MASK**                                                                           | Маска прерываний (Master PIC).                                                                        |
| `0xC012`                | Native| **IRQ_ACK**                                                                            | Подтверждение прерываний (Master PIC).                                                                |

| Устройство/Регистр      | Порт CPC (Legacy)     | 8-Bit Port (Native) | MMIO Адрес (Page:Offset)      | Примечания                                                                                            |
| :---------------------- | :-------------------- | :------------------ | :---------------------------- | :---------------------------------------------------------------------------------------------------- |
| **MMU: Slot Select**    | -                     | `0xDB`                | `0xC004` (Page 0)             |                                                                                                       |

**Заключение:** Предложенная архитектура обеспечивает:
*   **Совместимость:** Все legacy-порты остаются на своих местах и работают в предназначенном для них режиме.
*   **Расширяемость:** Новые устройства добавляются через MMIO без конфликтов.
*   **Логичность:** Системные регистры сгруппированы в MMIO, а их доступ через 8-битные порты является вторичным и зеркалирующим.
*   **Защиту:** Критичные регистры (управление слотами, режимами) доступны только из кода супервизора, работающего в правильном режиме.
