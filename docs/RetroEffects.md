## 1. 🎮 СПРАЙТОВАЯ ГРАФИКА (Sprite Effects)

### 🔹 **Транспарентность (Color Key Transparency)**
**Суть**: Один цвет становится невидимым  
**Пример**: Персонаж на фоне, пуля в воздухе  
**Реализация**:
```c
accel->transparent_color = 0x0000; // Черный = прозрачный
accel->use_transparency = 1;
accel->operation = OP_COPY;
```

### 🔹 **Инвертирование спрайтов (Sprite Inversion)**
**Суть**: Спрайт отображается в негативе  
**Пример**: Уязвимость босса, "эффект поражения"  
**Реализация**:
```c
accel->operation = OP_LOGIC;
accel->logic_op = LOGIC_OP_XOR; // Инвертируем пиксели
accel->fill_color = 0xFFFF;     // XOR с белым = инверсия
```

Фактически происходит следующее:
Результат = (Пиксель_из_источника XOR Пиксель_в_буфере) XOR fill_color

## 2. 🎨 КОМПОЗИЦИЯ И СЛОИ (Composition Effects)

### 🔹 **Наложение слоёв (Layer Blending)**
**Суть**: Два изображения смешиваются  
**Пример**: Туман, водная поверхность, стекло  
**Реализация**:
```c
accel->operation = OP_BLEND;
accel->blend_mode = BLEND_MODE_ADD; // Аддитивное смешивание
// Источник = вода, Назначение = фон
```

### 🔹 **Маскирование (Masking)**
**Суть**: Часть изображения скрывается маской  
**Пример**: Окно в стене, бинокль, прицел  
**Реализация**:
```c
accel->operation = OP_LOGIC;
accel->logic_op = LOGIC_OP_AND; // Оставляем только где маска = 1
// Маска в src, изображение в dst
```

## 3. ⚡ СИСТЕМНЫЕ ЭФФЕКТЫ (System Effects)

### 🔹 **Мозаика (Mosaic Effect)**
**Суть**: Изображение разбивается на крупные пиксели  
**Пример**: Телепортация, повреждение экрана  
**Реализация**:
```c
accel->operation = OP_LOGIC;
accel->logic_op = LOGIC_OP_AND;
accel->fill_color = 0xAAAA; // Шахматный паттерн для мозаики
```

### 🔹 **Заполнение областей (Area Fill)**
**Суть**: Быстрая заливка прямоугольников  
**Пример**: Фоны меню, полосы здоровья, платформы  
**Реализация**:
```c
accel->operation = OP_FILL;
accel->fill_color = 0x7C00; // Красный цвет
// Устанавливаем координаты и размер области
```

## 4. 🌌 ВИЗУАЛЬНЫЕ ЭФФЕКТЫ (Visual Effects)

### 🔹 **Тени и подсветка (Shadows & Highlights)**
**Суть**: Добавление теней для объёма  
**Пример**: Тень под персонажем, свечение  
**Реализация**:
```c
accel->operation = OP_BLEND;
accel->blend_mode = BLEND_MODE_ALPHA;
accel->fill_color = 0x0000;    // Черный для тени
// Нужен регистр прозрачности для интенсивности
```

### 🔹 **Мерцание (Flickering)**
**Суть**: Быстрое включение/выключение видимости  
**Пример**: Мигание предмета, призрачный враг  
**Реализация**:
```c
// Чередуем кадры с копированием и пропуском
if (frame_count % 2 == 0) {
    accel->operation = OP_COPY; // Видимый кадр
} else {
    // Пропускаем - невидимый кадр
}
```

## 5. 🕹️ ИГРОВЫЕ ЭФФЕКТЫ (Game Effects)

### 🔹 **Вспышка (Flash Effect)**
**Суть**: Кратковременная белая вспышка  
**Пример**: Взрыв, получение урона, магия  
**Реализация**:
```c
accel->operation = OP_LOGIC;
accel->logic_op = LOGIC_OP_OR;
accel->fill_color = 0xFFFF; // Белая вспышка
```

### 🔹 **Постепенное появление (Fade In/Out)**
**Суть**: Плавное изменение видимости  
**Пример**: Переход между уровнями, начало игры  
**Реализация**:
```c
// Многократное наложение черного с разной прозрачностью
for (int alpha = 0; alpha < 256; alpha += 16) {
    accel->operation = OP_BLEND;
    accel->blend_mode = BLEND_MODE_ALPHA;
    accel->fill_color = 0x0000; // Черный
    // Устанавливаем уровень прозрачности
}
```

## 6. 🖼️ ЭКРАННЫЕ ЭФФЕКТЫ (Screen Effects)

### 🔹 **Сдвиг экрана (Screen Shift)**
**Суть**: Смещение всего изображения  
**Пример**: Дрожание камеры, землетрясение  
**Реализация**:
```c
// Быстрое копирование всего буфера со смещением
accel->src_addr = 0x0000; // Весь экран
accel->dst_addr = 0x0000;
accel->src_x = offset_x;   // Смещение
accel->src_y = offset_y;
accel->width = 320; accel->height = 200;
```

### 🔹 **Обрезка по области (Clipping)**
**Суть**: Ограничение рисования областью  
**Пример**: Миникарта, диалоговое окно, HUD  
**Реализация**:
```c
accel->clip_x1 = 50; accel->clip_y1 = 30;
accel->clip_x2 = 270; accel->clip_y2 = 170;
// Все операции будут обрезаться по этим координатам
```

## 🎯 ПРАКТИЧЕСКИЙ ПРИМЕР: "Эффект получения урона"

```c
void damage_effect() {
    // 1. Красная вспышка
    accel->operation = OP_LOGIC;
    accel->logic_op = LOGIC_OP_OR;
    accel->fill_color = 0xF800; // Красный
    accel->control = START_BIT;
    
    // 2. Дрожание экрана (3 кадра)
    for (int i = 0; i < 3; i++) {
        accel->operation = OP_COPY;
        accel->src_x = random(-3, 3);
        accel->src_y = random(-3, 3);
        accel->control = START_BIT;
    }
    
    // 3. Постепенное восстановление
    for (int alpha = 255; alpha > 0; alpha -= 32) {
        accel->operation = OP_BLEND;
        accel->blend_mode = BLEND_MODE_ALPHA;
        accel->fill_color = 0x0000; // Затемнение
        // Установка прозрачности
    }
}
```
